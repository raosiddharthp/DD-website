# DataDomine Brand Assets

Private repository containing all brand assets, website files, 
and reference documents for DataDomine.

## Structure

- /marks — all SVG logo marks, wordmark variants, monogram variants
- /favicons — favicon package and web manifest
- /social — social media banners, covers, and avatar SVG files
- /open-graph — Open Graph images for each website page
- /slides — pitch deck slide templates
- /tearsheets — programme tearsheets and overview one-pager
- /email — email signature and response templates
- /thumbnails — course thumbnail template for Teachable
- /website — complete website HTML, CSS, and JS files
- /reference — brand reference documents and asset log
