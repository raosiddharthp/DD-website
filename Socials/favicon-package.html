Implementation Notes

The SVG favicon references modern browsers (Chrome 80+, Firefox 84+, Safari 16+). The sizes="any" attribute on the ICO link ensures that legacy browsers fall back correctly without ambiguity.

At 16×16 the Domine Mark is reduced to a 2px vertical with a 4px amber dot. This is the minimum legible rendering. At this size the amber dot reads as a distinct coloured cap above a white stem — the mark is identifiable even at the smallest browser tab scale.

The purpose: "any maskable" on the SVG manifest entry covers both standard and maskable icon contexts. If a dedicated maskable PNG is required (with safe-zone padding to 80% of canvas), export the 192×192 SVG with the mark scaled to approximately 60% of the canvas area.

All SVG sources are self-contained. No external dependencies. No filters, gradients, or shadows. Compliant with all DataDomine brand rules.
